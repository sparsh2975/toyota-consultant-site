# Toyota Consultant Website
React + Vite + Tailwind + Framer Motion.

    npm install
    npm run dev        # local
    npm run build      # outputs dist/

Deploy: push to GitHub and import in Netlify (netlify.toml is included), or drag the `dist` folder.
Edit all content in `src/data/config.js`. Replace `public/profile.jpg` for a new photo. Add car photos to `public/cars/`.
Forms save to Netlify Forms (Site → Forms) and also open WhatsApp with the details.
